# Тренажёр выводов R

Приложение для телефона: 500 выводов R (ANOVA, линейная регрессия с логарифмами и без, логистическая регрессия), к каждому 5 вопросов с разборами. Работает без интернета.

**Открыть и установить:** https://dinsimple1997-create.github.io/r-trainer/
В Chrome на Android: меню ⋮ → «Установить приложение».

## Как добавляются задания

1. Пишешь Claude в проекте, что добавить.
2. Claude показывает 2–3 примера новых заданий, ты согласуешь.
3. Claude собирает партию, проверяет числа и выкладывает в этот репозиторий.
4. В приложении появляется плашка «Вышло обновление» → «Обновить». Прогресс сохраняется на телефоне.

## Версии

- **1.0** (14.11.2026) — 500 выводов, 2500 вопросов, раздел «Как читать вывод».

## Для Claude: как пересобрать

Исходники в `tools/`. Из папки `tools/`:

```
python3 gen.py          # examples.json: генерация выводов и вопросов (numpy, scipy)
python3 build.py        # r-trainer.html: страница с данными и разделом «Как читать вывод»
python3 build_pwa.py .. # index.html, sw.js, manifest и иконки в корень репозитория
```

Перед выкладкой новой версии поменяй `VERSION`, `DATE` и текст «Что нового» в `build_pwa.py`: имя кэша в `sw.js` зависит от версии, и по нему телефон узнаёт об обновлении. Новые сценарии добавляются в `contexts.py`, новые виды выводов — функциями `gen_*` в `gen.py` и строкой в `PLAN`.
