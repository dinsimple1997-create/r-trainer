# Тренажёр R

Приложение для телефона. Работает без интернета. Разделы:

- **Тренажёр выводов R** — 660 выводов R с пятью вопросами и разборами к каждому: ANOVA, простая и множественная линейная регрессия (с логарифмами и без), логистическая и пуассоновская регрессия.
- **Методы** — объяснения линейной, множественной, логистической и пуассоновской регрессии простыми словами.
- **Как читать вывод** — короткие правила и калькулятор.
- **Тренажёр синтаксиса R** — 191 упражнение в 5 блоках (база, таблицы и индексы, функции и модели, ggplot2, tidyverse): перепечатать код и выбрать, что он делает.

**Открыть и установить:** https://dinsimple1997-create.github.io/r-trainer/
В Chrome на Android: меню ⋮ → «Установить приложение».

## Как добавляются задания

1. Пишешь Claude в проекте, что добавить.
2. Claude показывает примеры или выкладывает их на страницу для проверки, ты согласуешь.
3. Claude собирает партию, проверяет числа и выкладывает в этот репозиторий.
4. В приложении появляется плашка «Вышло обновление» → «Обновить». Прогресс сохраняется на телефоне.

## Для Claude: как пересобрать

Исходники в `tools/`. Из папки `tools/`:

```
python3 gen.py          # examples.json: выводы и вопросы (numpy, scipy); новые виды — в gen2.py
python3 syntax_bank.py  # syntax.json: упражнения тренажёра синтаксиса
python3 build.py        # r-trainer.html: страница со всеми разделами
python3 build_pwa.py .. # index.html, sw.js, manifest и иконки в корень репозитория
```

Перед выкладкой новой версии поменяй `VERSION`, `DATE` и текст «Что нового» в `build_pwa.py`: имя кэша в `sw.js` зависит от версии, и по нему телефон узнаёт об обновлении.

- Сценарии — в `contexts.py`. Виды выводов 1.0 — функции `gen_*` в `gen.py` (`PLAN`), с 1.1 — в `gen2.py` (`PLAN2`). Новые партии добавляй в конец: номера уже выпущенных примеров должны остаться прежними, иначе сохранённый прогресс съедет.
- `models.py` повторяет `glm.fit` из R (старт, правило остановки, число итераций) для binomial и poisson.
- Тексты разделов: `guide.html` («Как читать»), `methods.html` («Методы»), `syntax_ref.html` («Правила и источники»). Каркас и скрипты — `template.html`.
- Упражнения синтаксиса — вызовы `E(...)` в `syntax_bank.py`: код, правильный ответ, три неправильных, разбор и, если надо, что напечатает R.
