Как заниматься: в каждом упражнении сначала перепечатай код в поле под ним (пробелы и вид кавычек не важны, регистр букв важен), потом выбери, что этот код делает. Кнопки над полем вставляют символы, которые на телефоне искать дольше всего: <-, |>, ~, $.

Блок 4. ggplot2

Рецепт: ggplot(данные, aes(x, y, …)) + geom_…() + facet_…() + scale_…() + labs() + theme_…(). Слои соединяет +, а не |>.

  • Внутри aes() — то, что зависит от столбца: aes(color = sex). Вне aes() — константа: geom_point(color = "blue").
  • geom выбирают по типу данных: два числа — geom_point; одно число — geom_histogram / geom_density; число по группам — geom_boxplot / geom_jitter; число строк в группе — geom_bar; готовая высота — geom_col.
  • geom_smooth(method = "lm") — прямая регрессии с полосой ДИ.
  • xlim() выкидывает точки, coord_cartesian(xlim = …) только приближает.
  • Число как группа: factor(parity).
