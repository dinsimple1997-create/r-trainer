С чего начать любой вывод

  1. Строка с формулой (lm(…), aov(…), glm(…)): слева от ~ отклик Y, справа X или группа.
  2. Есть ли log() и с какой стороны. От этого зависит, брать ли e.
  3. Какая функция: aov — ANOVA; lm — линейная регрессия (или ANOVA, если справа группа); glm(…, family = binomial) — логистическая.
  4. Найди строку, о которой спрашивают, и бери числа из неё: Estimate, Std. Error, t (или z), p.

Наклон b₁: что это на самом деле

b₁ — на сколько единиц Y в среднем меняется Y, если X больше на 1 единицу. Больше ничего. Единицы b₁ — «единицы Y на одну единицу X».

Пример: масса поросёнка при отъёме (кг) от возраста отъёма (дни). R выдал (Intercept) = 1,00 и age = 0,24. Прямая: Ŷ = 1,00 + 0,24 · age.

Возраст, дниŶ = 1,00 + 0,24 × возрастРазница с предыдущим
201,00 + 4,80 = 5,80 кг
211,00 + 5,04 = 6,04 кг+0,24
221,00 + 5,28 = 6,28 кг+0,24
251,00 + 6,00 = 7,00 кг+0,72 за 3 дня (3 × 0,24)
  • Каждый +1 день → средняя масса на 0,24 кг больше. Это и есть b₁.
  • +k единиц X → среднее Y меняется на k × b₁. Сдвиг b₀ при этом не нужен — он сокращается.
  • Минус у b₁ → с ростом X среднее Y падает.
  • (Intercept) b₀ — прогноз при X = 0. Читать по смыслу можно, только если X = 0 есть в данных (возраст отъёма 0 дней — нет).
  • «в среднем»: конкретные поросята разбросаны вокруг прямой примерно на Residual standard error.
  • Опыт или наблюдение: если X назначали случайно — «увеличение X вызывает…»; если нет — «связано с…».
EN: Each 1-day increase in age at weaning is associated with a 0.24 kg increase in mean weaning weight.

Вывод по p: p < 0,05 → хотя бы одно среднее отличается (какое — F не говорит). p ≥ 0,05 → нет доказательств различий (но и равенство не доказано).

Сравнить две группы руками: SE = √(MSE × (1/n₁ + 1/n₂)); t = разница / SE; ДИ = разница ± qt × SE, df = df Residuals. MSE и df берём из всей таблицы, даже если сравниваем только две группы.

Контраст с коэффициентами c: g = Σ c·среднее; SE = √(MSE × Σ c²/n).

Группы в lm и glm: где «вторая» группа

Когда справа от ~ стоит группа, R делает из неё переменные 0/1. Первая по алфавиту группа становится референтной — её строки в выводе нет, она «спрятана» в (Intercept). Каждая строка вида dietB — это разница «B минус референтная».

  • Среднее B = 450 + 20 = 470; среднее C = 450 + 35 = 485.
  • C − B = 35 − 20 = 15: A сокращается. Отдельной строки для этого нет.
  • p в строке dietB проверяет «B = A», а не «B = 0».
  • F-statistic внизу — общий тест «все средние равны», тот же, что в ANOVA.

В glm то же самое, только на шкале log-odds: (Intercept) — log-odds референтной группы, строка группы — разница log-odds (см. ниже).

Логарифмы: два вопроса

  1. Y под log? Да → от коэффициентов (и концов ДИ, и сдвига) берём e. Говорим «в … раз» / «на … %» и слово медиана. Нет → e не берём.
  2. X под log? Да → при прогнозе подставляем ln X; в трактовке говорим «X в 2 раза» и умножаем b₁ на 0,693. Нет → «+1 к X».
МодельКак читать b₁Прогноз
y ~ x+1 к X → среднее Y + b₁b₀ + b₁·X
log(y) ~ x+1 к X → медиана Y × eb₁; % = (eb₁ − 1)·100; +k к X → × ek·b₁eb₀ + b₁·X (медиана)
y ~ log(x)X × 2 → среднее Y + 0,693·b₁; X × 10 → + 2,303·b₁b₀ + b₁·ln X
log(y) ~ log(x)X × 2 → медиана Y × 2b₁; +1 % X ≈ +b₁ % Yeb₀ + b₁·ln X

Проценты перемножаются. b₁ = −0,0184 на 1 единицу: на 10 единиц не 10 × 1,8 = 18 %, а e−0,184 = 0,832 → на 17 % ниже.

Не переводят через e: R², t, p, F.

Почему медиана: e от среднего логарифмов — это середина данных, а не их среднее. 2, 4, 8: среднее 4,67, а eсреднее ln = 4.

Логистическая регрессия

R считает всё на шкале log-odds. Цепочка туда и обратно:

вероятность p → шансы = p / (1 − p) → log-odds = ln(шансы)
log-odds → шансы = elog-odds → вероятность = шансы / (1 + шансы)

Пример: p = 0,20 → шансы 0,2/0,8 = 0,25 («1 к 4») → log-odds = ln 0,25 = −1,39.

Две группы: где «вторая» группа

Control (референтная)b₀ = −0,75e−0,75 = 0,4720,472 / 1,472 = 0,32

  • OR — отношение шансов, не вероятностей. Вероятности здесь 0,32 и 0,14: их отношение 2,3, а не 3.
  • p в строке groupVaccine проверяет H₀: β₁ = 0, то есть OR = 1 (шансы одинаковы).
EN: The odds of disease for vaccinated pigs are estimated to be e−1.10 = 0.33 times the odds for unvaccinated pigs (about 67% lower odds).

Три группы

Обе строки — против референтной A. OR «C против B» = ebC − bB (или ORC / ORB). Вероятность в C: eb₀ + bC / (1 + eb₀ + bC).

Непрерывный X

  • +1 к X → шансы × eb₁. +k к X → шансы × ek·b₁ (не k × OR).
  • % изменения шансов = (eb₁ − 1) × 100.
  • Вероятность при X₀: log-odds = b₀ + b₁·X₀ → шансы → вероятность.
  • Вероятность меняется неравномерно (S-кривая): постоянны только шансы «в разах».

Пуассоновская регрессия: glm(…, family = poisson)

Отклик — счёт: сколько случаев, драк, павших. Модель живёт в мире log(среднего счёта), поэтому любой коэффициент переводим через e.

Coefficients:

  1. Референт — первая по алфавиту группа (Control). Её нет среди строк: она в (Intercept).
  2. IRR = eb = e−0,9599 = 0,383. Частота диареи на ZnO составляет 0,383 от частоты на Control, то есть в 1 / 0,383 = 2,61 раза ниже, или на 62 % ниже.
  3. С offset (offset(log(pigdays)) или offset = log(pigdays)) eb₀ — частота на 1 поросёнко-день у референта: e−4,0451 = 0,0175, или 1,75 случая на 100 поросёнко-дней. Ожидаемый счёт = pigdays × частота.
  4. Передисперсия: Residual deviance / df = 60,339 / 27 = 2,23. Больше ~1,25 — SE занижены, нужен quasipoisson или MASS::glm.nb.
  5. Тест всей модели: 82,212 − 60,339 = 21,87 при df = 1.

Не путать: в логистической eb — отношение шансов (OR), в пуассоновской — отношение частот (IRR). Для непрерывного x: +1 к x умножает ожидаемый счёт на eb, +10 — на e10·b.

Множественная регрессия: lm(y ~ x1 + x2 + группа)

  1. Каждый коэффициент — «при прочих равных». startwt = 5,97: при +1 кг стартовой массы и тех же потреблении корма и поле среднесуточный привес выше на 5,97 г/сут.
  2. Прогноз: подставь все x. Дамми (sexGilt) умножается на 1 только для Gilt; для Barrow это слагаемое 0.
  3. t в строке — нужен ли предиктор, когда остальные уже в модели. F внизу — все предикторы вместе (H₀: все β при x равны 0).
  4. Residual df = n − число коэффициентов (с Intercept). Отсюда n и df для qt.
  5. Adjusted R² — для сравнения моделей с разным числом предикторов. car::vif больше 4 — разобраться, больше 10 — серьёзная коллинеарность.

  • 2b — кнопка xʸ.
  • Проверка знака: отрицательный коэффициент → множитель меньше 1.
